# ⏳ Kalkulator Waktu

**Kalkulator Waktu** adalah aplikasi web interaktif bertema *digital wellbeing* yang membantu pengguna menyadari seberapa banyak waktu yang terpakai di media sosial dan menggantinya dengan aktivitas produktif.

## ✨ Fitur Utama
1. **Landing Page Informatif**: Pengenalan singkat tentang pentingnya kesadaran waktu digital (*digital wellbeing*).
2. **Kalkulator Waktu Media Sosial**: Menghitung akumulasi jam, hari penuh, dan estimasi jumlah buku yang sebenarnya bisa selesai dibaca dalam satu tahun berdasarkan durasi *scrolling* harian.
3. **Pengatur Waktu Fokus (Pomodoro Timer)**: Timer interaktif dengan pilihan mode Fokus (25 menit), Istirahat (5 menit), dan *Deep Work* (45 menit).
4. **Tantangan Harian Tanpa Gawai (*Offline Challenge*)**: Daftar misi harian bebas layar dilengkapi indikator progres (*progress bar*).

## 🛠️ Teknologi yang Digunakan
- **HTML5** (Struktur semantik)
- **CSS3** (Desain responsif, Flexbox & CSS Grid)
- **JavaScript (Vanilla JS)** (Logika perhitungan, *countdown timer*, dan manipulasi DOM)

## 🚀 Cara Menjalankan & Publikasi di GitHub Pages
1. Unggah seluruh file (`index.html`, `style.css`, `script.js`, dan `README.md`) ke repositori GitHub Anda.
2. Buka tab **Settings** di repositori GitHub Anda.
3. Pilih menu **Pages** di bilah samping kiri.
4. Pada bagian **Branch**, pilih `main` (atau `master`) lalu klik **Save**.
5. Tunggu beberapa saat hingga tautan website aktif dan siap diakses secara publik.
